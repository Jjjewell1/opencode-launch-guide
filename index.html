Launch a New Site

A step-by-step guide using opencode, GitHub, Coolify, and Cloudflare

opencode → GitHub → Coolify → Cloudflare

1 Build with opencode

opencode is an AI-powered CLI that writes code, runs commands, and manages your project from the terminal. You describe what you want, and it generates the files.

Install opencode

# macOS / Linux
curl -fsSL https://opencode.ai/install.sh | sh

# Windows (PowerShell)
iwr -useb https://opencode.ai/install.ps1 | iexINSTALL

Create your project

# Make a new folder and enter it
mkdir my-new-site && cd my-new-site

# Launch opencode
opencodeTERMINAL

Once inside the opencode prompt, describe your site:

Build me a single-page portfolio site with a hero section,
an about section, a projects grid, and a contact form.
Use a dark theme with blue accents. Keep it to one HTML file.PROMPT

opencode will create the files, install dependencies if needed, and can even run a local dev server so you can preview the result.

Tip: You can iterate conversationally. Say things like "make the header sticky" or "add a footer with social links" and opencode will update the code in place.

2 Push to GitHub

Once the site looks right, get it into a GitHub repo so Coolify can pull from it.

Initialize the repo

git init
git add .
git commit -m "Initial site build"TERMINAL

Create the GitHub repo and push

You can do this from the terminal with the GitHub CLI (gh), or create the repo on github.com and push manually.

# Option A: Using GitHub CLI (fastest)
gh repo create my-new-site --public --source=. --push

# Option B: Manual
# 1. Go to github.com/new and create the repo
# 2. Then run:
git remote add origin https://github.com/YOUR_USERNAME/my-new-site.git
git branch -M main
git push -u origin mainTERMINAL
Tip: You can let opencode do this for you. Just say "push this to GitHub" and it will run the commands above.

3 Deploy with Coolify

Coolify is a self-hosted PaaS (like Heroku, but on your own server). It pulls your code from GitHub, builds it, and keeps it running.

Connect your GitHub repo

  1. Open your Coolify dashboard.
  2. Navigate to your project (or create a new one).
  3. Click + Add Resource and select Application.
  4. Choose GitHub as the source and authorize Coolify if prompted.
  5. Select the repository and branch (main) you just pushed.

Configure the build

  1. Set the Build Pack to Static (or Nixpacks if you have a framework).
  2. Set the Publish Directory to / for a root-level static site, or /dist if using a build step.
  3. Coolify will assign an internal port (usually 80 for static sites).

Deploy

Click Deploy. Coolify pulls your code from GitHub, builds the container, and starts serving it. You'll see build logs in real time.

Done: Your site is now running on your Coolify server. You can access it via the internal IP or the preview URL Coolify provides.

Set up auto-deploy (webhook)

Every time you push to GitHub, Coolify can automatically redeploy:

  1. In Coolify, go to your app's Webhooks tab and copy the webhook URL.
  2. In GitHub, go to your repo → Settings → Webhooks → Add webhook.
  3. Paste the Coolify URL and save.
Full automation: From now on, every git push (or asking opencode to "push and deploy") triggers a zero-downtime redeploy.

4 Expose with Cloudflare

Cloudflare Tunnels let you serve your self-hosted site on a real domain with SSL, without opening ports on your firewall.

Prerequisites

  • A domain added to Cloudflare (nameservers pointed to Cloudflare).
  • cloudflared installed on your Coolify server.
# Install cloudflared on your server
# Debian / Ubuntu
curl -fsSL https://pkg.cloudflare.com/cloudflare-main.gpg | sudo tee /usr/share/keyrings/cloudflare-main.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/cloudflare-main.gpg] https://pkg.cloudflare.com/cloudflared $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/cloudflared.list
sudo apt update && sudo apt install -y cloudflaredSERVER

Create the tunnel

# Authenticate with Cloudflare (opens a browser login)
cloudflared tunnel login

# Create a named tunnel
cloudflared tunnel create my-site-tunnel

# Route your domain to the tunnel
cloudflared tunnel route dns my-site-tunnel www.yourdomain.comSERVER

Configure the tunnel

Create or edit the config file at ~/.cloudflared/config.yml:

tunnel: YOUR_TUNNEL_ID
credentials-file: /root/.cloudflared/YOUR_TUNNEL_ID.json

ingress:
  - hostname: www.yourdomain.com
    service: http://localhost:80
  - service: http_status:404config.yml

Replace localhost:80 with whatever port Coolify's reverse proxy (Traefik) is serving on.

Run the tunnel

# Run in foreground (for testing)
cloudflared tunnel run my-site-tunnel

# Or install as a system service (production)
sudo cloudflared service install
sudo systemctl enable cloudflared
sudo systemctl start cloudflaredSERVER
Live! Visit https://www.yourdomain.com. Your site is now served through Cloudflare with automatic HTTPS, DDoS protection, and global CDN caching.

5 Quick Reference

The full workflow in one view:

# 1. Build with opencode
opencode
# "Build me a landing page for a coffee shop"

# 2. Push to GitHub
git add . && git commit -m "New site"
git push

# 3. Coolify auto-deploys via webhook

# 4. Cloudflare tunnel serves it live at your domainFULL WORKFLOW
Remember: The first time through each phase requires manual setup (GitHub repo, Coolify project, Cloudflare tunnel). After that, the workflow is just: edit in opencode → push → auto-deploy → live.
